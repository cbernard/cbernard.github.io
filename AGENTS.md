# AGENTS.md

## Comments

Keep them rare and short. Comment a magic number, a workaround, or an ordering
constraint — something the code cannot say by itself. One line is usually
enough.

Do not restate the code below, and do not narrate a change: comments describe
the code as it is, not what it used to be or why it was edited.

## Commits

One line, and nothing else. A short subject in the imperative — "Add the about
page", "Fix the lockfile for npm ci" — with no body under it: no explanation,
no bullet list, and no trailer of any kind, `Co-Authored-By` included.
