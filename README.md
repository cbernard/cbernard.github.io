# folio-2025

Portfolio de Charly Bernard — designer & développeur front-end.

Site statique construit avec [Astro](https://astro.build), animé avec GSAP,
swup et Lenis. Déployé automatiquement sur GitHub Pages à chaque push sur
`main`.

## Commandes

| Commande          | Action                              |
| :---------------- | :---------------------------------- |
| `npm install`     | Installe les dépendances            |
| `npm run dev`     | Serveur de dev sur `localhost:4321` |
| `npm run build`   | Build vers `./dist/`                |
| `npm run preview` | Sert le build en local              |

Node 22 (voir `.nvmrc`).
